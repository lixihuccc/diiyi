把授权边界，
画在每一页上。

这套原型对应 V2 的 RBAC 需求：功能权限决定「能不能做」，数据权限决定「能对哪些记录做」。 界面不隐藏规则——每个页面都显示当前身份、数据范围与本页所需权限码；每个被禁用的操作都就地说明原因。

设计语言取自访问控制台账：分级授权条、带线的表格、权限码作为证据。没有卡片堆叠，也没有装饰性的渐变。

建议评审路径

以运营人员查看 Agent 列表agent:list / self 以只读访客查看同一列表viewer 运营人员打开他人公开 Agent40302 运营人员直接输入系统管理地址403

切换身份使用页面右上角的「预览身份」。切换后菜单、按钮、表格行与权限注记会一起变化； 被隐藏的菜单不是置灰，而是不渲染。直接访问无权限页面会被路由守卫送往 403 页面。

原型中的三个身份对应：超级管理员（跳过校验）、运营人员（业务全权 / 仅本人数据）、 只读访客（仅 list 与 read）。只读访客用于评审只读状态，是待确认角色，不是 V2 的既定默认角色。

颜色

  • 骨白 #EFEEE8：画布
  • 纸白 #FAFAF6：内容面
  • 墨黑 #151B19：侧栏与标题
  • 石墨 #5E6763：次级文本
  • 松绿 #1E5B49：授权与主操作
  • 印红 #A23B2B：拒绝与危险

字体

  • Noto Serif SC · 页面标题、品牌
  • IBM Plex Sans SC · 界面与正文
  • IBM Plex Mono · 权限码、ID、时间
  • 正文行长 < 80 字符；表格数字右对齐
  • 不使用全大写标签与装饰性小标题

原则

  • 边界可见：分级授权条 + 权限注记
  • 台账而非卡片：用线组织信息
  • 一种权威色：松绿只用于授权
  • 拒绝必须解释：40300 / 40301 / 40302
  • 动效只回应操作：切换、展开、保存
